# เช็คอินงาน (Work Check-in)

แอป Android (Kotlin + Jetpack Compose) เตือนให้สแกนนิ้วเข้า/ออกงาน และบันทึกเวลาที่กดเช็คจริง

## ความสามารถ
- **วันนี้**: แถบสัปดาห์ (ปัดซ้าย/ขวาเปลี่ยนสัปดาห์, ไอคอนปฏิทินเลือกวัน), รายการ "สแกนนิ้วเข้า/ออก" กดวงกลมเพื่อบันทึกเวลาปัจจุบัน
  - วันที่ผ่านมาแล้ว กดแล้วเลือกเวลาที่สแกนจริงได้
  - กดค้างที่รายการ เพื่อข้าม (เช่น ลา/หยุด) หรือระบุเวลาเอง
  - กดรายการที่เสร็จแล้ว เพื่อแก้เวลา เปลี่ยนเป็น "ข้าม" หรือยกเลิกกลับเป็นยังไม่เช็ค
  - ตัวนับ 🔥 = จำนวนวันติดต่อกันที่เช็คครบ
- **เพิ่ม**: ตั้งชื่อ, เวลาเข้างาน, เวลาออกงาน (รองรับกะดึกข้ามวัน), วันทำงานในสัปดาห์, เตือนซ้ำทุก 5/10/15/30 นาทีถ้ายังไม่เช็ค (ไม่เกิน 2 ชม.)
- **แจ้งเตือน** ตรงเวลาที่ตั้ง มีปุ่มบนการแจ้งเตือน: "เช็คอิน/เช็คเอาท์" (บันทึกเวลาทันที), "ข้าม", "เตือนอีก 30 นาที"
- **ประวัติ**: แท็บกราฟ (สรุป 30 วัน, สถานะ 7 วันล่าสุดแบบ ✓/✗ กดขยายดูย้อนหลังทั้งหมดได้, กราฟเร็ว/ช้ากว่ากำหนด 14 วัน) และแท็บรายการย้อนหลัง 90 วัน, ปุ่มแชร์เป็นข้อความ
- **ตารางเวลา**: ดู/แก้/ปิดชั่วคราว แต่ละตาราง และเตือนถ้าแอปยังไม่ได้สิทธิ์แจ้งเตือน

## วิธี build
**Android Studio**: File > Open เลือกโฟลเดอร์นี้ รอ Gradle sync แล้วกด Run

**GitHub**: push ขึ้น GitHub แล้ว workflow `Build APK` จะ build ให้ ดาวน์โหลด APK ได้ที่แท็บ Actions > artifacts

**Command line** (มี Android SDK แล้ว): `./gradlew assembleDebug` ได้ไฟล์ที่ `app/build/outputs/apk/debug/app-debug.apk`

## หมายเหตุการแจ้งเตือน
- Android 13+ ต้องกดอนุญาตการแจ้งเตือนตอนเปิดแอปครั้งแรก
- การเตือนหลักใช้ `setAlarmClock` (แบบเดียวกับนาฬิกาปลุก) และ Android 13+ ได้สิทธิ์ปลุกตรงเวลาอัตโนมัติ (`USE_EXACT_ALARM`)
- หน้า "ตารางเวลา" มีปุ่ม **ทดสอบแจ้งเตือน** และแสดงเวลาเตือนครั้งถัดไป ถ้ามีสิทธิ์ไหนขาดจะมีการ์ดสีแดงพร้อมปุ่มไปแก้
- มือถือบางยี่ห้อ (Xiaomi, OPPO, vivo ฯลฯ) ควรปิดการประหยัดแบตเตอรี่ให้แอปนี้ ไม่งั้นระบบอาจตัดการเตือน

## โครงสร้าง
```
app/src/main/java/com/workcheckin/app/
  data/     Room: Shift (ตารางเวลา), CheckRecord (เวลาที่เช็ค), logic คำนวณรายการ/สถิติ
  notify/   AlarmManager + BroadcastReceiver (เตือน, ปุ่มบันทึก, ตั้งปลุกใหม่หลังรีบูต)
  ui/       หน้าจอ Compose: Today, ShiftEdit, Shifts, Progress
```

## Release (signed APK)
- เวอร์ชันอยู่ที่ `app/build.gradle.kts` (`versionName` / `versionCode` เพิ่มทุกครั้งที่ออกเวอร์ชันใหม่)
- ตั้ง GitHub Secrets 2 ตัว: `KEYSTORE_BASE64` (ไฟล์ keystore แปลงเป็น base64) และ `KEYSTORE_PASSWORD` (alias ค่าเริ่มต้น `northxbar`)
- push ขึ้น main แล้ว workflow จะ build APK ที่ sign แล้ว และสร้าง/อัปเดตหน้า GitHub Release ตามเลข `versionName`
- เก็บไฟล์ keystore ไว้ให้ดี ถ้าหาย จะอัปเดตแอปทับตัวเดิมไม่ได้
